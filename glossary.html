Ablation study
Removing parts of a model to measure their contribution. Go 3, module 3.8
Activation function
The nonlinear function in a neuron, such as tanh or ReLU. Go 1, module 1.3
Active learning
Choosing new runs where the current model is most uncertain. Go 1, module 1.7
Adam
An adaptive gradient-based optimiser widely used for training PINNs. Go 2, module 2.2
Adaptive cruise control (ACC)
An automated system that keeps a set gap to the vehicle ahead using radar. Go 3, module 3.2
Automatic differentiation
Computing exact derivatives of a program by applying the chain rule to its operations. Go 1, module 1.4
Baseline
A simple reference model that a new method must outperform. Go 2, module 2.1
Bias
An adjustable offset added inside a neuron. Go 1, module 1.3
Boundary condition
A constraint on the solution at the edges of the domain. Go 2, module 2.3
Calibration
Agreement between stated and actual coverage of uncertainty intervals. Go 2, module 2.6
Candidate library
The set of possible terms an equation might contain. Go 2, module 2.4
Car-following model
A model of how a driver adjusts speed in response to the vehicle ahead. Go 3, module 3.2
Carbon price
A charge per tonne of CO₂ emitted, used in scenarios to drive emission reductions. Go 3, module 3.5
CFL condition
Courant–Friedrichs–Lewy limit: information must not travel more than one cell per step. Go 2, module 2.3
Closure term
A term representing unresolved processes in a coarse model. Go 2, module 2.7
Collocation point
A point where the equation residual is evaluated during training. Go 1, module 1.5

Coverage for a specific input or subgroup. Go 2, module 2.8
Conformal prediction
A method that turns any model's errors on calibration data into prediction intervals with coverage guarantees. Go 2, module 2.8

Combining model predictions with observations to estimate a system's state. Go 3, module 3.7
Data drift
A change in the distribution of inputs or outcomes after deployment. Go 2, module 2.8

A model learned from examples without built-in laws. Go 1, module 1.1

A neural operator with a branch network for the input function and a trunk network for the query location. Go 2, module 2.5
