Learning as optimisation: loss, gradients, autodiff

Training a model means minimising a loss by walking downhill along its gradient. Learning rate, momentum and local minima decide whether training succeeds; automatic differentiation computes the gradients.

Read the transcript

How does a network learn? We define a loss: a single number that measures how wrong the model is, such as the average squared difference between predictions and data. Learning means finding the weights that make the loss small. Imagine the loss as a landscape of hills and valleys over all possible weights. Gradient descent stands on this landscape, feels which way is downhill, and takes a step. The gradient tells the direction, and the learning rate sets the step size. Too small and training crawls. Too large and it jumps across valleys or even flies off. Real landscapes have many valleys, called local minima, and momentum, which keeps some of the previous step, can help roll past small ones. Popular optimisers such as Adam adapt the step for each weight. Computing gradients by hand is impossible for millions of weights, so software uses automatic differentiation, which applies the chain rule exactly. SciML uses the same machinery to differentiate a network with respect to its inputs, which is how physics enters the loss.

Loss functions

A loss turns 'how wrong' into one number. The most common is the mean squared error:

L(w) = (1/N) Σ (ŷᵢ(w) − yᵢ)²

Squaring makes all errors positive and punishes big ones more. In SciML we add terms that measure how badly the model breaks a physical law; minimising the total balances data and physics.

Gradient descent by hand

Take L(w) = (w − 3)², gradient 2(w − 3), start w = 0, learning rate η = 0.1:

w₁ = 0 − 0.1 × 2 × (0 − 3) = 0.6; w₂ = 0.6 − 0.1 × 2 × (0.6 − 3) = 1.08

Each step closes 20% of the gap to the minimum at w = 3. With η = 1.0 the step overshoots to w = 6, then back to 0: it never settles. With η above 1.0 it diverges.

Momentum, Adam and local minima

Real losses are bumpy, with many valleys. Momentum keeps a fraction of the last step, like a ball rolling, so it can pass small bumps and move faster along gentle slopes. Adam (Kingma and Ba 2015) adapts the step size for each weight and is the default for training physics-informed networks. Stochastic gradient descent uses random mini-batches of data, which adds helpful noise.

Automatic differentiation

Automatic differentiation (autodiff) records every arithmetic operation in the model and applies the chain rule backwards (backpropagation). It gives exact derivatives, not finite-difference approximations, at a cost similar to one extra model evaluation. Crucially for SciML, autodiff can also give the derivative of the network's output with respect to its input, such as dŷ/dt, which is exactly what a differential equation needs.

How SciML uses it

In a physics-informed network, autodiff gives dŷ/dt at any time t; the loss then penalises dŷ/dt + k ŷ ≠ 0. You will build exactly this in module 1.5 and Go 2.

Remember

  • A loss turns 'how wrong' into one number; training minimises it.
  • Gradient descent steps downhill: w ← w − η × gradient.
  • The learning rate must be neither too small nor too large; momentum and Adam help.
  • Automatic differentiation computes exact gradients, including with respect to inputs.

Words and links

New words

Loss function
A number measuring how wrong a model is; training minimises it.
Gradient
The vector of derivatives of the loss with respect to each parameter.
Learning rate
The step size of gradient descent.
Momentum
Carrying over part of the previous update to smooth and speed up descent.
Automatic differentiation
Computing exact derivatives of a program by applying the chain rule to its operations.
