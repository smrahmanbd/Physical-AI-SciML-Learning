Hybrid modelling: physics plus learned corrections

A hybrid model keeps a physics model and learns only what it gets wrong. It needs fewer data than pure machine learning and extrapolates far more safely, as long as the physics part is sound.

Spoken overview
Read the transcript

Often we have a physics model that is good but not perfect. The textbook Greenshields model says traffic speed falls in a straight line as density rises. Real roads curve away from that line. One option is to throw the physics away and fit a flexible machine learning model to the data. Another is to keep the physics and learn only the correction: the hybrid approach. The learned part now has an easy job, modelling a small, smooth residual, so it needs fewer data and stays well behaved. Crucially, where there are no data, the hybrid falls back on the physics instead of inventing something. In our example, with speed observations only up to sixty vehicles per kilometre, a pure polynomial model is off by hundreds of kilometres per hour at high density, the physics alone is off by about thirteen, and the hybrid by about three and a half. Other hybrid patterns include learning unknown parameters of a physics model, learning closure terms for unresolved processes, and gray-box models. In this module you will compare the three approaches as you change how much data you have.

Residual hybrids, step by step

(1) Fit or choose the physics model, here Greenshields v = vf(1 − ρ/ρj). (2) Compute residuals r = vdata − vphysics. (3) Fit a small, regularised model to the residuals (here a quadratic). (4) Predict v = vphysics + r̂. Keep the correction small and smooth; a huge learned correction means the physics is wrong, not just imperfect.

Beyond the data

With 20 observations up to 60 veh/km, the errors at higher densities are: ML only (degree-4 polynomial) about 870 km/h, physics only about 13 km/h, hybrid about 3.6 km/h. With data up to 100 veh/km all improve, but the hybrid stays best. The explorer lets you see how quickly the ML-only model goes wrong once it leaves its data.

Try it

Set the highest observed density to 40, then to 120. How do the three errors change? Which model is most stable?

Other hybrid patterns

Parameter learning: a network predicts physical parameters from context (for example, capacity from weather and lighting), then the physics model runs. Closure learning: a network represents an unresolved term inside the equation, trained through the solver (universal differential equations). Gray-box models mix known and learned blocks in a system diagram. All keep interpretable structure.

When to choose a hybrid

Choose a hybrid when the physics captures the main structure but misses details, data are limited, and extrapolation matters (new conditions, rare events). Avoid it if the physics is badly wrong (the correction will dominate) or if data are abundant and conditions never change (pure ML may be simpler).

Research angle

Hybrid car-following (IDM plus a learned residual) and hybrid traffic-flow models are active topics; see module 3.2.

Words and links

New words

Hybrid model
A model combining a physics-based component with a data-driven component.
Residual learning
Learning the error of a physics model and adding it as a correction.
Closure term
A term representing unresolved processes in a coarse model.
Gray-box model
A model mixing known physical structure with learned components.
Greenshields model
A linear speed–density relation for traffic, from 1935.
