Spoken overview
Read the transcript

A PINN solves one problem: one set of boundary conditions, one source, one parameter value. Change the input and you must train again. Operator learning removes that limitation. An operator is a map from a whole function to a whole function: from a heat source pattern to the temperature field it creates, or from a traffic demand profile to the resulting congestion pattern. We generate example pairs with a classical solver, then train a neural operator to reproduce the map. Afterwards, new inputs are solved almost instantly. DeepONet, by Lu and colleagues, uses two networks: a branch network reads the input function at sensor points, a trunk network reads the location where we want the answer, and their dot product gives the output. Fourier neural operators, by Li and colleagues, learn in frequency space and can work at different grid resolutions. The catch: the training inputs must cover the kinds of inputs you will meet later. In this module you will learn a solution operator from a few example pairs, and see exactly how many you need.

Functions versus operators

A network usually learns a function: numbers in, numbers out. An operator takes a function in and gives a function out: G: f ↦ u. For −u″ = f with u(0) = u(1) = 0, G is the solution operator of the Poisson problem. Learning G means one trained model solves the problem for every source f, not just one.

How many examples?

In the explorer the inputs are built from 8 sine shapes, so the operator restricted to them has 8 degrees of freedom. With 2 or 4 training pairs the error on new inputs is over 100%; with 8 or more it drops to essentially zero. Real input families are richer, so neural operators often need hundreds to thousands of pairs; the variety of the pairs matters as much as their number.

Try it

Increase training pairs from 1 to 10. At which number does the error collapse? Does adding more grid points change that number?

DeepONet and Fourier neural operators

DeepONet (Lu et al. 2021): u(x) ≈ Σk bk(f) tk(x), branch b, trunk t. The PyTorch lab trains one on 500 pairs in about 10 seconds and reaches about 3% error on new inputs. Fourier neural operators (Li et al. 2021) apply learned filters in frequency space; they are resolution-independent and excel at fluid-like problems. Both can be made physics-informed by adding residual terms (PI-DeepONet).

Transport uses

Operator learning can map demand profiles to congestion patterns along a corridor, weather fields to road-surface temperature, or emissions maps to concentration fields, giving fast surrogates for scenario studies and real-time control. The training data come from validated simulators, so their limits carry over.

"""2.5 A small DeepONet (Lu et al. 2021) for the same map f -> u, -u'' = f. Install: pip install torch.
Branch net encodes the input function at m sensor points; trunk net encodes the query location x; output = dot product."""
import torch, numpy as np
torch.manual_seed(0); rng = np.random.default_rng(0); m, K = 24, 8
x = np.linspace(0, 1, m + 2)[1:-1]
A = (np.diag(2*np.ones(m)) - np.diag(np.ones(m - 1), 1) - np.diag(np.ones(m - 1), -1))*(m + 1)**2
def sample(n):
    a = rng.standard_normal((n, K))/np.arange(1, K + 1)
    F = a @ (np.sin(np.outer(np.arange(1, K + 1), np.pi*x))*(np.arange(1, K + 1)[:, None]*np.pi)**2*0.1)
    return torch.tensor(F, dtype=torch.float32), torch.tensor(np.linalg.solve(A, F.T).T, dtype=torch.float32)
F, U = sample(500); Ft, Ut = sample(100)
branch = torch.nn.Sequential(torch.nn.Linear(m, 64), torch.nn.Tanh(), torch.nn.Linear(64, 40))
trunk = torch.nn.Sequential(torch.nn.Linear(1, 64), torch.nn.Tanh(), torch.nn.Linear(64, 64), torch.nn.Tanh(), torch.nn.Linear(64, 40))
X = torch.tensor(x, dtype=torch.float32).reshape(-1, 1)
opt = torch.optim.Adam(list(branch.parameters()) + list(trunk.parameters()), lr=1e-3)
scale = U.std(); fs = F.std()
for it in range(1, 4001):
    pred = branch(F/fs) @ trunk(X).T                             # (n_functions, m points)
    loss = ((pred - U/scale)**2).mean(); opt.zero_grad(); loss.backward(); opt.step()
    if it % 1000 == 0: print(f"iteration {it}: loss {loss.item():.2e}")
with torch.no_grad():
    pt = branch(Ft/fs) @ trunk(X).T*scale
    print(f"relative error on 100 new inputs: {((pt - Ut).norm(dim=1)/Ut.norm(dim=1)).mean().item():.3f}")
Branch and trunk networks trained on 500 pairs. Requires pip install torch; about 10 seconds.

Words and links

New words

Operator
A mapping from one function to another, such as from a PDE's source to its solution.
DeepONet
A neural operator with a branch network for the input function and a trunk network for the query location.
Fourier neural operator
A neural operator that applies learned filters in Fourier (frequency) space.
Solution operator
The map from a problem's inputs to its solution.
Resolution independence
The ability to evaluate on grids different from those used in training.
