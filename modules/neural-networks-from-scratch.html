Spoken overview
Read the transcript

A neural network is just a function with many adjustable knobs. The basic unit is a neuron. It takes inputs, multiplies each by a weight, adds them up with a bias, and passes the result through a nonlinear function such as the hyperbolic tangent, which looks like a soft step. One neuron can only make one soft step. But add many neurons side by side, each with its own position and steepness, and add their outputs with new weights, and you can build almost any smooth curve. This is the universal approximation idea. Stack layers and the network can build features of features. Learning means adjusting the weights so that the network's output matches the data, which is the topic of the next module. Networks are powerful but have no idea about physics: they only know the examples they saw. In this module you will add neurons one by one and watch a network bend into the shape of a function, and see what it struggles with.

الشبكة العصبية ليست سوى دالة لها مقابض كثيرة قابلة للضبط. ووحدتها الأساسية هي العصبون: يأخذ المدخلات، ويضرب كلاً منها في وزن، ويجمعها مع انحياز، ثم يمرر الناتج عبر دالة غير خطية مثل الظل الزائدي، الذي يشبه درجة ناعمة. العصبون الواحد لا يصنع إلا درجة ناعمة واحدة، لكن إذا وضعنا عصبونات كثيرة جنباً إلى جنب، لكل منها موضعه وانحداره، وجمعنا مخرجاتها بأوزان جديدة، استطعنا بناء أي منحنى أملس تقريباً. هذه هي فكرة التقريب الشامل. وبتكديس الطبقات تستطيع الشبكة بناء خصائص من خصائص. والتعلم يعني ضبط الأوزان بحيث تطابق مخرجات الشبكة البيانات، وهذا موضوع الوحدة التالية. الشبكات قوية لكنها لا تعرف شيئاً عن الفيزياء، فهي لا تعرف إلا الأمثلة التي رأتها. ستضيف في هذه الوحدة عصبونات واحداً تلو الآخر وتشاهد الشبكة تنحني لتأخذ شكل دالة، وترى ما الذي يصعب عليها.

A single neuron

A neuron computes a = tanh(w·x + b). The weight w sets how steep the step is; the bias b sets where it is. The hyperbolic tangent squeezes any number into the range −1 to 1. Other common activation functions are the ReLU, max(0, z), and the sigmoid. Without a nonlinear activation, any stack of layers would collapse into a single straight line.

Many neurons, many shapes

A layer of n neurons followed by a weighted sum gives y = Σ vⱼ tanh(wⱼ x + bⱼ) + c. With enough neurons this can approximate any continuous function on a bounded range (the universal approximation theorem, Cybenko 1989; Hornik 1991). Deeper networks (more layers) often need far fewer neurons for complex functions.

Parameter count for one input, n hidden neurons, one output: n weights + n biases + n output weights + 1 output bias = 3n + 1.

What networks cannot do alone

A network learns only from its examples. It struggles with sharp jumps (smooth neurons blur them), knows nothing outside the data range, and can give confident nonsense. It also has no built-in respect for physics: a network trained on traffic speeds can predict negative speeds. Adding physics, in Go 1 module 1.5 and throughout Go 2, is how SciML fixes this.

Remember

  • A neuron computes a weighted sum and applies a nonlinear activation.
  • Many neurons together can approximate any smooth function.
  • A one-hidden-layer network with n neurons has 3n + 1 parameters.
  • Networks know only their data and nothing about physics.

Words and links

New words

Neuron
A unit computing an activation of a weighted sum of inputs plus a bias.
Activation function
The nonlinear function in a neuron, such as tanh or ReLU.
Weight
An adjustable multiplier on a connection.
Bias
An adjustable offset added inside a neuron.
Universal approximation
The result that networks with enough neurons can approximate any continuous function on a bounded range.
